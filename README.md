# Python Mini Projects 🐍

A collection of beginner Python programs I created while learning programming fundamentals and improving my problem-solving skills.

## Projects

### 1. Area of Circle
Calculates the area of a circle using the radius entered by the user.

### 2. Even/Odd Checker
Checks whether a given number is even or odd.

### 3. Simple Calculator
Performs basic arithmetic operations:
- Addition
- Subtraction
- Multiplication
- Division

### 4. Fibonacci Sequence
Generates a Fibonacci sequence for the number of terms entered by the user.

### 5. Palindrome Checker
Checks whether a word or number is a palindrome.

## Concepts Practiced

- Variables and data types
- User input
- Conditional statements
- Loops
- Arithmetic operators
- String slicing
- Basic problem solving

Python 🐍
